MTI Labs

Repository containing the laboratory work completed for the **Méthodes et Technologies de l'Implémentation (MTI)** module.
The purpose of these labs was to explore and apply fundamental software engineering principles by implementing practical examples in **Python**.

##  Topics Covered

### SOLID Principles
- Single Responsibility Principle (SRP)
- Open/Closed Principle (OCP)
- Liskov Substitution Principle (LSP)
- Interface Segregation Principle (ISP)
- Dependency Inversion Principle (DIP)

### Design Patterns
- Creational Patterns
- Structural Patterns
- Behavioral Patterns

### Object-Oriented Programming
- Classes and Objects
- Inheritance
- Polymorphism
- Abstraction
- Encapsulation


##  Note

This repository was created as part of the **MTI (Méthodes et Technologies de l'Implémentation)** coursework and serves as a collection of laboratory exercises completed throughout the semester.
